# Сайт личного бренда Алибек Ермагамбетов

Статический адаптивный сайт без сборщика: достаточно открыть `index.html` или загрузить папку на любой хостинг.

## Что редактировать в первую очередь
- `site-config.js` — Instagram/TikTok, статистика, менеджер, WhatsApp, email и отображение цен.
- `index.html` — тексты, блоки, проекты и формулировки.
- `styles.css` — цвета, размеры, отступы и визуальный стиль.
- `assets/` — фотографии/визуалы, взятые из предоставленного медиакита.

## Форма заявки
Форма работает без backend: после заполнения создаёт готовое сообщение и открывает WhatsApp менеджера. Никакие данные не сохраняются на сервере.

Если позже нужна CRM/Bitrix24, достаточно заменить обработчик формы в `script.js` на запрос к вашему webhook/API.

## Показ цен
В `site-config.js`:
```js
showPrices: true
```
Поставьте `false`, чтобы вместо цен показывалось «По запросу».
